原版日语惯例核对（来源: ja.minecraft.wiki「鉱石」/「原石」页面，实际抓取核对，非猜测）:
  · 深層鉱石 = 「深層鉄鉱石」「深層石炭鉱石」「深層ダイヤモンド鉱石」… → 深層X鉱石（不是「深層岩のX鉱石」）【已核实】
  · 原石 = 「鉄の原石」「銅の原石」「金の原石」、原石ブロック = 「鉄の原石ブロック」 → Xの原石【已核实】
    ※ 任务书里假设的「粗製鉄 / 粗い鉄」经核实不成立：原版日语用的是「鉄の原石」。因此本 mod 的「粗X」不符合原版惯例
      （「粗銅」在日语里指冶金中间产物，作为物品名不自然）。该组内部写法是统一的，属于"统一但与原版不一致"。
  · 防具 = 鉄のヘルメット/鉄のチェストプレート/鉄のレギンス/鉄のブーツ、锭 = 鉄インゴット、桶 = 水入りバケツ、
    音楽ディスク = 音楽ディスク → 本 mod 这些用法正确，未列为问题。
  · 板类原版没有对应物；本 mod 统一用「X板」（鉄板/銅板/鋼板…），内部一致，判为正确。

===== 类别 5: 中国語の直訳・不自然な造語 =====

【直訳】key = item.potato_s_t.star_chart_tome
  zh:  星仪图之章
  现在: 星儀図の書
  问题: 「星儀図」不是日语词（「星仪」是中文的浑仪/星盘＋图），日语里星图叫「星図」；这是照抄中文词形的结果。
  建议: 星図の書   [置信度 高]

【直訳】key = item.potato_s_t.thermal_metal
  zh:  热力金属
  现在: 熱力金属
  问题: 「熱力」在日语里不单独作定语（只有「熱力学」这样的固定词），这是中文「热力」的直译；日本人会说「サーマル」或「熱〜」。
  建议: サーマルメタル   [置信度 中]

【直訳】key = block.potato_s_t.lithium_battery
  zh:  三元聚合物锂电池
  现在: 三元系ポリマーリチウム電池
  问题: 语序照搬中文「聚合物锂电池」；日语的电池名是「リチウムポリマー電池」（或リチウムイオンポリマー電池），「ポリマーリチウム電池」不是日语说法（「三元系」本身用得对）。
  建议: 三元系リチウムポリマー電池   [置信度 中]

【直訳】key = item.potato_s_t.photovoltaic_component
  zh:  光伏元件
  现在: 光起電力素子
  问题: 两个 *_component 键在中文里同为「元件」（lithium_battery_component 也是「元件」），日语却一个译成「素子」、一个译成「部品」（リチウム電池部品），同一概念两种接尾辞。
  建议: 光起電力部品（与 リチウム電池部品 统一；若坚持「素子」则应把锂电那键也改成「リチウム電池素子」）   [置信度 中]

【直訳】key = block.potato_s_t.fluid_exchanger
  zh:  容器换流器
  现在: 容器換装器
  问题: 「換装」在日语里是"更换装备/换装"（装备を換装する），与"在容器之间换流体"无关；这是把中文「换流」按字形换成了另一个词。该机器实际功能是把左槽容器里的流体变成对应的桶。
  建议: 流体交換器   [置信度 中]

【直訳】key = block.potato_s_t.salt_decomposer
  zh:  盐分解器
  现在: 塩分解構築器
  问题: 中文是「盐分解器」（分解装置），日语却多出一个「構築」，写成"分解＋构筑"，语义自相矛盾（机器实际是把盐分解成氯化钠/粗矿）；本 mod 同类机器统一用「〜装置」（電解装置/加熱装置/放熱装置）。
  建议: 塩分解装置   [置信度 高]

【直訳】key = block.potato_s_t.power_capturer
  zh:  动力能源捕获器
  现在: 動力エネルギーキャプチャー
  问题: 「動力」＋「エネルギー」是中文「动力能源」的重复直译；日语里把装置叫「〜キャプチャー」也不自然（キャプチャ是动作名词），本 mod 其他机器都用「〜装置」。
  建议: エネルギー捕獲装置（或 動力捕獲装置）   [置信度 中]

【直訳】key = block.potato_s_t.distillation_operator
  zh:  分馏塔操作器
  现在: 分留塔操作器
  问题: 「操作器」是中文词形的直译，日语里几乎不用（日语的技术词是「操作装置」或「操作パネル」）；同族的控制器已写作「コントローラー」，两个键文体也不齐。
  建议: 分留塔操作装置   [置信度 中]

【直訳】key = block.potato_s_t.low_generator
  zh:  低级发电机
  现在: 低級発電機
  问题: 日语「低級」用于产品时带有"劣质、下等"的贬义（低級品・低級な冗談），用于机器等级不自然；分级一般用「初級／下位／小型」。
  建议: 初級発電機（或 下位発電機）   [置信度 低]
  说明: 本 mod 另有「高級金属ブロック」（对应 advanced），若要与它对称，可考虑保留「低級」；这一点取决于作者想不想保留"低/高"对称的用词。

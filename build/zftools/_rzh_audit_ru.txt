原版俄语惯例核对（来源: Minecraft Wiki / wiki-minecraft.ru / minecraftsearch，实际抓取核对，非猜测）:
  · 矿石 = Железная руда / Медная руда（形容词与 руда 阴性一致）
  · 深层矿石 = Глубинносланцевая железная руда，即「Глубинносланцевая + X-овая руда」【已核实】
    ※ 本 mod 用的是「X-овая руда в глубинном сланце」（前置词短语），与原版构词不一致。
  · 原矿 = Необработанное железо / Необработанная медь / Необработанное золото
    ※ 本 mod 的 10 个原矿（Необработанный вибраниум…Необработанное серебро）性别全部正确，包括中性 «серебро»，
      未发现问题，不计入问题条数。
  · 桶 = Ведро воды / Ведро лавы / Ведро молока（本 mod 的柴油/汽油桶合此式，只有油桶不合）
  · 创造 = Творческий（Творческий режим）；本 mod 用 «Креативный»
  · 盔甲 = Железный шлем / Железный нагрудник / Железные поножи / Железные ботинки
    ※ 本 mod 用 «Шлем из вибраниума / Поножи из титанового сплава» 句式，属常见 mod 惯例，格与数一致，未发现问题。
  · 锭/板/粉 = Железный слиток / Железная пластина / Железная пыль
    ※ 本 mod 的「Xовый слиток」「Xовая пластина」全部与名词性别一致（含 Стальная/Медная/Алюминиевая），未发现问题。
      其中 вибраниум 与 звёздная сталь 两键用「Слиток + 属格」（Слиток вибраниума / Слиток звёздной стали），
      这与它们整套物品的「из + 属格」写法一致，是自然的俄语，不算错误。
  · 音乐唱片 = Пластинка（本 mod 正确）。未发现拉丁字母残留、未发现未翻译键。

===== 类别 3: 语法与用词（грамматика и лексика）=====

【语法】key = item.potato_s_t.starfall_pendant
  zh:  星轨坠
  现在: Звёздный подвесок
  问题: «подвесок» 是过时/口语的阳性形式，现代俄语规范名词是阴性 «подвеска»（украшение-подвеска）或 «кулон»（阳）; 若取规范的 «подвеска»，则形容词必须是 «Звёздная»，现在的 «Звёздный» 与规范名词性别不一致。
  建议: Звёздная подвеска（或 Кулон звездопада）   [置信度 高]

【语法】key = item.potato_s_t.carbon
  zh:  碳粉
  现在: Угольная пыль
  问题: «Угольная пыль» 意思是"煤粉/煤尘"（来自 уголь = 煤），而本物品是元素碳（zh 碳粉 / en Carbon Dust），物质名不对；族内 «Железная пыль»、«Титановая пыль» 用的才是材料形容词。
  建议: Углеродная пыль   [置信度 中]

【语法】key = item.potato_s_t.thermal_metal
  zh:  热力金属
  现在: Термальный металл
  问题: «термальный» 在俄语里主要用于水和泉（термальные воды/источники），指材料或设备时规范形容词是 «термический»（ср. термическая обработка）；这里应换成 «Термический металл»。
  建议: Термический металл   [置信度 中]

【语法】key = block.potato_s_t.lithium_battery
  zh:  三元聚合物锂电池
  现在: Тройная полимерная литиевая батарея
  问题: «тройная» 意为"三倍的/三重的"，是中文「三元」的直译；电池术语里三元（NCM）体系是 «трёхкомпонентная»，且锂聚合物电池的固定说法是 «литий-полимерная»（语序也不是 «полимерная литиевая»）。
  建议: Трёхкомпонентная литий-полимерная батарея   [置信度 中]

【语法】key = block.potato_s_t.salt_decomposer
  zh:  盐分解器
  现在: Разлагатель соли
  问题: «разлагатель» 不是俄语规范词（有 «нагреватель/разделитель/растворитель»，但没有 «разлагатель»），是照着中文「分解器」生造的名词；装置名应用 «установка разложения»。
  建议: Установка разложения соли   [置信度 中]

【语法】key = block.potato_s_t.salt_dryer
  zh:  晒盐机
  现在: Солесушилка
  问题: 俄语不这样自由合成复合词（соле- + сушилка 属生造），本 mod 其他机器都用词组（«Разливочная машина»、«Разделитель воздуха»）。
  建议: Сушилка для соли   [置信度 中]

【语法】key = block.potato_s_t.micro_crusher
  zh:  微型粉碎机
  现在: Микро-дробилка
  问题: 俄语正字法要求前缀 «микро-» 连写（ср. микроволновка, микрорайон），带连字符的 «Микро-дробилка» 是拼写错误（有连字符的只有 «мини-» 这类外来前缀）。
  建议: Микродробилка   [置信度 中]

【语法】key = block.potato_s_t.distillation_operator
  zh:  分馏塔操作器
  现在: Оператор ректификационной колонны
  问题: «оператор» 在俄语里首先指人，而且 «оператор ректификационной колонны» 是真实存在的职业名称（装置操作工），玩家会把它读成一个"人"而不是方块；中文原词「操作器」指的是执行装置。
  建议: Исполнительный блок ректификационной колонны（或 Рабочий блок ректификационной колонны）   [置信度 低]
  说明: 没有公认的单一译法；关键是避开会读成"人/岗位"的 «Оператор»。若作者坚持用 «Оператор»，至少加 «Блок-оператор …» 以示是方块。

【统一】key = block.potato_s_t.alloy_smelter_port

transl: 新增文言文语言包 lzh.json（510 键）+ 跨片术语收口

用户：「如果你想的话可以再加一套文言文翻译」。做了 —— 而且**不是装饰**：
取证确认 1.21.1 原版自带 `lzh` 语言（launcher 资源索引里有
`minecraft/lang/lzh.json`，142 种语言之一），所以这份文件在游戏里
**能直接选到**。

## 取证先行：三条改变做法的事实

`_rzh_probe_locales.py` / `_rzh_probe_lzh_meta.py` / `_rzh_vanilla_names.py`
从 launcher 资源索引里直接把原版语言文件读出来：

1. **lzh 是官方语言**（`assets/indexes/asset-index.json` 的
   `minecraft/lang/lzh.json` 条目在盘）。
2. **原版 lzh 自带语言元数据**：`language.name = 文言`、`language.region = 華夏`。
   1.21 的语言菜单读**这个文件**决定显示名 ⇒ 我们的 lzh.json 必须带上这两条，
   否则语言列表里显示的是原始翻译键。于是 `zh_cn` 的 508 键 + 这 2 条 = **510 键**。
3. **原版 lzh 用繁体**（`鐵礦 / 鐵璞 / 鐵錠 / 金剛劍 / 鐵胄`）⇒ 译稿全部走繁体。
   这一条我原先搞反了（先按简体派活，取证后逐一发消息纠偏）。

## 怎么产的

508 个键按类别切成三片并行翻译（物品名 138 / GUI+tooltip 235 / 消息+成就 135），
每片带同一份术语表 `_rzh_lzh_glossary.md`（材料、机器、成就标题全部钉死），
各片自检「键集/键序/占位符序列/`\n` 个数/单位总量」后才交。

合并器 `_rzh_lzh_merge.py` 是**门**不是复制粘贴：三片键集两两不相交且合起来
**正好等于 zh_cn**（缺一个 ⇒ 游戏里那一条会静默回落成英文），逐键核对
`%s`/`%%`/`%1$s` 序列与 `\n` 个数，任何一步不过一个字节都不落盘。

## 分片翻译的真实代价：跨片术语撞车

片内自洽，合起来才暴露。`_rzh_lzh_consist.py` 扫出并收口了这些：

| 正文里的写法 | 物品名那一份 | 结果 |
|---|---|---|
| 頭盔 / 胸甲 / 靴子 / 鍬 | 胄 / 鎧 / 靴 / 鍁（照原版 lzh：鐵胄/鐵鎧/鐵靴/鐵鍁） | 收口 |
| 鋰電池原件（3 处） | 鋰電池元件 | 收口（中文原文本轮就把「原件」纠成「元件」） |
| 三元聚合物鋰電池 | 鋰電池 | 收口 |
| 扳手 / 碳粉 | 扳鉗 / 印墨 | 收口 |
| 盔亦照及 | 胄亦照及 | 收口 |
| 熱金 | 熱力金屬 | **保留** —— 那是图纸图例的简写（图例本身写明全称，格子放不下） |

## 我自己捅的两个洞（都是机械校验抓出来的，不是我"再看一遍"看出来的）

全域替换踩了同一类坑两次，教训是同一条：**替换词若是另一个词的真子串，必须限键**。

1. `碳粉 -> 印墨` 没限键，把 `item.potato_s_t.carbon`（碳粉，煅烧产物）也换成了
   「印墨」，它与 `item.potato_s_t.toner`（墨粉）成了同一个名字。
   ⇒ 限到 3 个键 + 定点回填 + 加一条"碳粉/墨粉必须不同名"的复检。
2. `冶煉爐 -> 合金爐` 没限键，把方块 `alloy_smelter_part` 改成了「合金合金爐」；
   而且**限键修的是将来，修不了已经落盘的** —— 界面三条里的叠字还剩着，
   是靠复读整个文件找出来的。
   顺带纠正一个我自己的误判：`gui.alloy_smelter.name` 显示的是**整台机器**
   （= 方块 `alloy_smelter_part`「合金冶炼炉」），不是主控也不是外壳部件；
   中文原文三条界面本来就写「合金冶炼炉」，我原本要改它是**没事找事**。

## 门与工具（新增）

* `_rzh_lzh_verify.py`：A 结构 / B 与 zh_cn 对照（键集、键序、占位符、换行、
  逐字相同白名单、字形）/ C 原版真有 lzh / D 台账认得 lzh。**失败项 = 0**。
* `_rzh_lzh_merge.py`：合并门（见上）。
* `_rzh_lzh_glyphcheck1.py`：字形检查**不靠我手写黑名单** —— 把原版
  `zh_cn.json` 与 `lzh.json` 按同键等长对齐，反推简→繁字表（要求该字原版繁体
  从不出现，挡掉用词差异噪声），再查译稿。**残留简体字形 = 0**。
  过程中它自己也有两个 bug，都修了：把**标点**（原版 zh_cn 用「…」、lzh 用「⋯」）
  当成字形对；以及把「面/器/只/言」这类简繁同形字当简体字，误报一片。
* `_rzh_lzh_check_part.py` / `_rzh_lzh_show.py` / `_rzh_lzh_consist.py` /
  `_rzh_lzh_sameok.py` / `_rzh_lzh_fix.py`。
* 白名单 `LZH_SAME_OK`（32 条：简繁同形的物料名与纯格式串）**只存一份**在
  `_rzh_touched.py`，合并器与门都从那里取 —— 存三份迟早会漂，漂了的白名单
  就是偷偷放宽判据。每条都经 `_rzh_lzh_sameok.py` 逐字判定过。

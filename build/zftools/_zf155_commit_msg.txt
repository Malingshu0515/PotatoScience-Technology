ZF155 通用升级模板：全游戏所有升级都能用它 + 冲突即禁用（0.12）

用户原话：「能不能加个通用升级模板 所有mod需要升级模板升级都可以用它 如果有冲突则不可以使用
（然后给振金剑加个配方 钛合金剑用这个和振金升级 之前所有的振金装备下界合金模板也改成这个）
获取方式；下界合金升级模板 围一圈铝锭」。拍板：**真·通用**（含原版下界合金）。

① 新物品 `potato_s_t:universal_upgrade_template`（原版 `SmithingTemplateItem` 子类：
   tooltip 白拿原版「升级 / 适用于 / 原料」三段式，末尾补一行规则；贴图 16x16 脚本画的**占位**）+
   五语各 7 键（物品名 / 升级 / 适用于 / 原料 / 底物槽 / 材料槽 / 规则）；
② 获取方式（用户指定）：`crafting_shaped` **八块铝锭围一圈 + 中间一张下界合金升级模板** → 通用模板 x1
   （与原版那张"模板 + 7 钻石 + 1 下界岩 → 模板 x2"的复制配方形状不同、不打架）；
③ **真·通用**：`UniversalUpgradeTemplate` 在 `ServerStartedEvent` + `OnDatapackSyncEvent`（登录 / `/reload`）
   把每条 `minecraft:smithing_transform` 的模板槽**原地**加宽成「原模板 ∪ 通用模板」
   （`CompoundIngredient`）—— 用 NeoForge 的官方口子 `RecipeManager.replaceRecipes`，
   **零反射、零 Mixin**；**id 一个字不变**（不加副本 ⇒ JEI 不会出现两条一样的升级，
   表里锻造配方总数装前装后都是 38）；
④ 纹饰一律跳过：源码实证 `TrimPatterns.getFromTemplate` = `template.is(pattern.templateItem())`
   （`TrimPatterns.java:59`）⇒ 图案与模板物品绑死，通用模板没有图案、`assemble` 必返空
   ⇒ 加宽它只会造出"匹配得上却出不了东西"的假配方（理由码 `trim-pattern-bound`，原版 18 条全跳过）；
⑤ **冲突即禁用**（用户那句「有冲突则不可以使用」）：底物能对上同一件、附加物也能对上同一件、
   结果却不同的两条升级，**都不许**用通用模板（判据取物品级"双槽重合"，比签名相等更严）；
⑥ 三个槽是包私有 final ⇒ 走官方编解码器 JSON 往返 + **逐物品保真复核**（注册表里每件物品逐一比对
   三个槽同真同假），任何一处不一致就整条放弃；只认**恰好**是 `SmithingTransformRecipe` 的配方
   （子类会丢字段 ⇒ `foreign-serializer`）；
⑦ 振金剑终于可合成（钛合金剑 + 振金锭 + 通用模板），4 件振金护甲的模板也换成它 ——
   **下界合金模板不再能升振金**（用户要求「也改成这个」，探针 B6 负对照钉住）。

## 一、模组介绍 / Mod Overview

### 中文

**PotatoS&T（土豆科技）** 是一套工业科技向的整合玩法模组：挖矿 → 粉碎 → 冶炼 → 压制 → 合金 → 接电，
把一条完整的材料链和一张小型电网焊在一起。

- **两种资源**：**FE**（NeoForge Energy，机器用电）与 **Power**（动能 —— 从原版机械里"接"出来的动力，
  经发电机变回电）。机器不会凭空发电，你得先有动能。
- **矿石与粗矿**：16 种矿石方块（含深层变种）+ 对应的**粗矿**（可粉碎成粉再冶炼）；矿石都挂了
  `c:` 社区标签，别的 mod 的机械也认。
- **材料链**：板 / 锭 / 粒 / 粉 / 线轴 / 合金 … 全部走 `c:` 标签，**换 mod 不换配方**。
- **机器**：微型粉碎机、电解机、晒盐机、灌装机、液压机、盐分解构器、电力高炉、合金冶炼炉、
  加氢脱硫反应仓、空气分离器、氨气组成室、燃烧反应室、酸性反应室、采油机、锂电池构造间、
  大型柴油发电机、**流体转化器**、**饮料罐装机** …（含多台多方块结构机器）。
- **流体**：原油 / 柴油 / 汽油 / 石脑油 / 液化气 / 氢 / 氧 / 氯 / 硫酸 / 氨 / 氮 / 二氧化碳 …
  全部挂 `c:` 流体标签，与别的 mod 的同类流体**同一个标签就是同一种料**。
- **装备**：钛合金 / 星璨钢 / **振金**三套（振金**无限耐久**，带猛砸技能与斩首被动）。
- **进度**：**46 条**进度从第一台微型粉碎机一路带你走到酸性反应室（一个页签、四条支线、不做无用功）。
- **语言**：简体中文 / English / 日本語 / Русский（另附文言 lzh，共 5 份 lang）。
- **集成**：**JEI**（有配方就有分类，没装也能玩）、**Jade**（显示储能）、**帕秋莉手册**（内置教程）、
  **Curios**（饰品栏）、**Mekanism**（化学品容器）、IE / 沉浸原油 / 机械动力（靠 `c:` 标签互通）。

### English

**PotatoS&T** is an industrial tech mod: you mine ore, crush it, smelt it, press it, alloy it, and wire
the whole thing into a small power grid.

- **Two resources**: **FE** (NeoForge Energy, what machines spend) and **Power** (kinetic energy you
  capture from vanilla machinery and turn back into electricity with a Generator). No free energy.
- **Ores & raw ore**: 16 ore blocks (with deepslate variants) plus their raw items (crush -> smelt),
  all on community `c:` tags so other mods' machines recognise them.
- **Material chain**: plates / ingots / nuggets / dusts / spools / alloys - everything on `c:` tags, so
  switching mods does not mean switching recipes.
- **Machines**: micro crusher, electrolyzer, salt dryer, filling machine, hydraulic press, salt
  decomposer, electric blast furnace, alloy smelter, hydrodesulfurization chamber, air separator,
  ammonia synthesis chamber, combustion chamber, acidic reaction chamber, oil pump, lithium battery
  plant, diesel generator controller, **Fluid Converter**, **Beverage Canning Machine** (plus several
  multiblock structures).
- **Fluids**: crude oil, diesel, gasoline, naphtha, LPG, hydrogen, oxygen, chlorine, sulfuric acid,
  ammonia, nitrogen, carbon dioxide... all on `c:` fluid tags.
- **Gear**: titanium alloy / Star Steel / **vibranium** (vibranium is unbreakable, with a ground-slam
  skill and a beheading passive).
- **Advancements**: **46**, one tab, four branches, no busywork steps.
- **Languages**: Simplified Chinese / English / Japanese / Russian (plus Literary Chinese - five files).
- **Integrations**: **JEI** (optional), **Jade**, **Patchouli** (built-in guide book), **Curios**,
  **Mekanism** (chemical containers), IE / Immersive Petroleum / Create (via `c:` tags).

## 二、0.13 更新公告 / 0.13 Update Notes

### 中文

**0.13 是三件事：把教程做出来、把兼容打通、把"看着像坏了"的地方全部修掉。**

**① 教程与体验**
- 新增 **帕秋莉教程手册**《土豆科技指南》（0.12 ZF148 起手册就是硬前置）。
- **重力装置 / 探矿仪**换上正式贴图；钛合金装备图标重画；热力金属贴图与图纸方向修正。
- 流体**动画**改成和原版水一样（不再"整块平移"的感觉）。

**② 兼容（这一版的重点）**
- **灌装机 × Mekanism**：喷气背包这类 Mek 气体物品现在**能被灌进本模组的氢/氧/氯/硫酸**
  （按 `c:` 同名标签 1:1 映射成 Mek 化学品；Mek 是软依赖，没装就照旧）。
- **Curios 饰品栏**：星璨钢头盔进头饰槽、Mek 喷气背包进背饰槽（Curios 自此为硬前置）。
- **流体与粉尘跨 mod**：`c:` 标签补齐，IE / 沉浸原油 / 机械动力 / Mekanism 的同类料互通。
- **硫磺共享**给别的 mod（`c:dusts/sulfur`）。
- **饮料罐装机 + 空罐 + 可乐**（另一条线做的新机器与物品）。

**③ 新机器：流体转化器**
- 把本模组的流体按**同名 `c:` 标签 1:1** 转成**别的 mod 的同标签流体**（实测：我们的柴油 ⇄ 沉浸原油的柴油）。
- 修了三处：**样板可以换**（空容器右键把旧样板装走）、**拒绝时不再把桶里的流体倒进世界**、
  **按接入面分工**（上/下面 = 样板，侧面 = 原料，抽出来的永远是产物）—— 用泵就能把样板给上。

**④ 新方块：磁铁块 + 6 个粗矿块**
- **磁铁块**（9 磁铁 ↔ 1 块）；**粗铝/粗钴/粗镍/粗银/粗钨/粗铀块**（9 粗矿 ↔ 1 块），
  锂 / 锰 / 钛 / 振金不做块。7 张贴图是这一版**自己画的**（石头底 + 从对应粗矿物品采样来的矿斑）。

**⑤ 修 bug**
- 振金 / 星璨钢（含钛合金）的护甲、剑、镐、斧、锹、锄**之前根本附不了魔**（附魔台不出、铁砧插不上）——
  病根是它们没挂原版"装备类型"标签（`minecraft:head_armor` / `swords` / `axes` …），现已全部补齐。
- 删除**扳手**与**物品形式的电力高炉**（前者有 bug 不修，后者由方块形态取代）。
- 灌装机改成**什么都能往槽里放**，能不能灌由灌装那一步判断（原来三道门会先把东西挡在外面）。

### English

**0.13 is three things: ship the guide, open up cross-mod compatibility, and fix everything that
looked broken.**

**1) Guide & polish**
- New **Patchouli guide book** (since 0.12 ZF148 Patchouli is a required dependency).
- Real textures for the **Gravity Device** and **Ore Detector**, redrawn titanium armour icons, a fixed
  Thermal Metal texture and recipe direction.
- Fluid **animation** now behaves like vanilla water.

**2) Compatibility (the headline of this version)**
- **Filling Machine x Mekanism**: Mekanism gas items such as the jetpack can now be filled with our
  hydrogen / oxygen / chlorine / sulfuric acid (`c:` tag mapping, 1:1, Mekanism stays optional).
- **Curios**: the Star Steel helmet and Mekanism's jetpack get their own trinket slots.
- **Fluids and dusts interoperate across mods** via `c:` tags (IE, Immersive Petroleum, Create,
  Mekanism). **Sulfur** is shared too.
- **Beverage Canning Machine**, empty cans and cola (another work stream).

**3) New machine: the Fluid Converter**
- Converts our fluids into another mod's fluid of the **same `c:` tag**, 1:1 (measured: our diesel <->
  Immersive Petroleum's diesel). Three fixes followed: you can now **change the sample**, a refused pour
  **no longer spills the bucket into the world**, and the fluid handler is **split by face**
  (top/bottom = sample, sides = input, draining always yields the product).

**4) New blocks: Magnet Block + six raw ore blocks**
- **Magnet Block** (9 magnets <-> 1 block) and **raw aluminium / cobalt / nickel / silver / tungsten /
  uranium blocks** (9 raw ore <-> 1 block); lithium, manganese, titanium and vibranium deliberately get
  none. All seven textures were **drawn for this release** (stone base with specks sampled from the
  matching raw ore item).

**5) Bug fixes**
- Vibranium / Star Steel (and titanium) armour, swords and tools **could not be enchanted at all** -
  they were missing from vanilla's equipment-type tags (`head_armor`, `swords`, `axes`, ...); fixed.
- Removed the **wrench** and the **item form of the Electric Blast Furnace** (the block form replaces it).
- The Filling Machine now **accepts anything in its slot**; whether it can be filled is decided at the
  filling step instead of by three gates at the door.

## 三、0.14 更新公告 / 0.14 Update Notes

### 中文

**0.14 = 版本线抬到 0.14 + 振金剑两处战斗改动。**

- **版本线 0.13 → 0.14**：`gradle.properties` 里的 `mod_version` 是全工程唯一一处版本号，
  所有钉版本号/成品文件名的判据一起跟平；成品改名 `release/PotatoST-0.14.jar`（0.13 留档）。
- **振金剑新增「斩首」被动（口径 B：只有猛砸技能击杀才算）**：
  用 **Shift+右键猛砸**砸死的生物掉落**它自己的头颅** —— 僵尸头 / 骷髅头 / 凋灵骷髅头 / 苦力怕头 /
  猪灵头 / 末影龙首；**玩家掉本人头颅**（头颅上就是他本人的皮肤）；**原版没有头颅物品的生物
  （牛/猪/蜘蛛/尸壳/溺尸…）不掉**。平砍**不算**（判据是猛砸**自己的伤害类型**，不是"手里拿着剑"）。
- **猛砸伤害重做**：伤害基数从"玩家基础伤害（**不含**手持武器）"改成**玩家当前攻击伤害**
  （含手持武器那一份），并且**吃附魔加成**（锋利 / 亡灵杀手这类），而且是**逐目标**算的
  —— 亡灵杀手对亡灵加、对牛不加。**实测**（真服务端，量血量差）：空手 12.79 → +9 攻击力 21.65；
  亡灵杀手 V 打僵尸 25.09 / 打牛 13.0（= 无附魔）；锋利 V 打牛 16.0。

**0.14 追加：整个模组现在可配置（配置界面 · 零新依赖）。**

- **一个文件管全部**：`config/potato_s_t-common.toml`（首次启动生成）。游戏里也能改 ——
  **模组列表 → PotatoS&T → 配置**（NeoForge 自带界面，五语种都有翻译）。
- **你点名的三项**：① **黑洞是否一次性**（默认开）：关掉之后放完黑洞**只抽干电力条、装置不损坏**；
  ② **引力装置蓄力时长**：默认 **30 秒**（5~60 可调，**老版本是 25 秒**）；
  ③ **单块锂电池容量**：默认 **4,000,000 FE**（1M~20M 可调，多方块总容量 = 块数 × 本值）。
- **另外 8 项**（我加的）：黑洞存活 20 秒 / 一次最多搬 1500 块 / 扫描半径 40 格 / 是否吸生物 /
  视界是否虚空伤害；引力装置储能 8M FE；锂电池每面速率 65,536 FE/t、一座最多 800 块。
- **不是必须依赖项**：配置界面用的是 NeoForge 自带的，`neoforge.mods.toml` 依赖清单与上一版
  **一字不差**；装了 Configured / Cloth Config 之类也读同一份配置，不装照样能改。
- 改完**即时生效**（不用重启）：实测同一块电池 4M→12M 当场变，蓄力 5 秒 = 100 tick。

- **0.14 追加（ZF188）配置界面归属**：装了「配置界面」(Configured) 就**让它接管**模组列表里的「配置」按钮
  （它的界面更好看）；**没装**则自动回落到 NeoForge 自带界面。依赖清单仍然**一字未动**。
  ⚠ 装了它之后，NeoForge 自带那个界面就点不到了 —— 想回去就在 Configured 里关掉强制接管或卸掉它。

### English

**0.14 = the version line moves to 0.14, plus two combat changes to the vibranium sword.**

- **Version line 0.13 -> 0.14**: `mod_version` in `gradle.properties` is the single source of truth;
  every gate that pinned the version or the release file name moved with it. The artifact is now
  `release/PotatoST-0.14.jar` (the 0.13 jar stays as history).
- **New passive on the vibranium sword - Beheading (option B: only the slam skill counts)**: mobs killed
  with the **ground slam (sneak + right-click)** drop **their own head** - zombie head, skeleton skull,
  wither skeleton skull, creeper head, piglin head, dragon head. **Players drop their own head** (with
  their own skin). Mobs that have no head item in vanilla (cow, pig, spider, husk, drowned...) drop
  nothing extra. Ordinary swings do **not** count - the check is the slam's **own damage type**, not
  "what is in your hand".
- **Ground slam damage reworked**: the base is now your **current attack damage** (the attribute value,
  which already includes the weapon you hold) instead of the bare base value that ignored the weapon,
  and it **benefits from enchantments** (Sharpness, Smite and friends) - applied **per target**, so
  Smite hurts the undead and leaves everything else alone. Measured on a real server (health delta):
  bare hand 12.79 -> +9 attack damage 21.65; Smite V 25.09 on a zombie but 13.0 on a cow (same as no
  enchantment); Sharpness V 16.0 on a cow.

**0.14 addition: the whole mod is configurable now (with an in-game screen and zero new dependencies).**

- **One file for everything:** `config/potato_s_t-common.toml` (created on first launch). You can also
  edit it in game via **Mods -> PotatoS&T -> Config** (NeoForge's built-in screen, translated into all
  five languages the mod ships).
- **The three you asked for:** (1) **one-shot black hole** (default on) - turn it off and firing only
  drains the energy bar, the device survives; (2) **gravity device charge-up time** - default **30 s**
  (5-60 s; the old version was 25 s); (3) **lithium battery capacity per block** - default
  **4,000,000 FE** (1M-20M; total = blocks x this value).
- **Eight more (my pick):** black hole lifetime 20 s / 1500 blocks per hole / 40-block scan radius /
  pull entities / void damage; gravity device buffer 8M FE; battery transfer rate 65,536 FE/t and
  800 blocks per multiblock.
- **Not a required dependency:** the screen is NeoForge's own, and the dependency list in
  `neoforge.mods.toml` is byte-identical to the previous release. Configured / Cloth Config read the
  same spec if you have them; if you do not, editing the TOML still works.
- **Applies live** (no restart): a battery block went 4M -> 12M the moment the value changed, and a
  5 s charge-up is 100 ticks.

- **0.14 follow-up (ZF188) - who owns the Config button:** if you have **Configured** installed it takes
  over the Config button in the mod list (its GUI is nicer); if you do not, the mod falls back to
  NeoForge's built-in configuration screen. The dependency list is still byte-identical.
  Note: with Configured installed, NeoForge's own screen is no longer reachable - turn off Configured's
  forced menu or remove it if you want it back.
